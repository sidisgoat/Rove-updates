# Rove Updates

This public repository hosts Rove Android release APKs and the OTA update manifest.

- `update.json` is published automatically by the private `sidisgoat/Rove` GitHub Actions workflow.
- APK binaries are attached to GitHub Releases in this repository.
- Do not manually edit the manifest while the release workflow is running.

The initial manifest advertises no update. It is replaced automatically after the first successful signed release.
